# Project Build Plan
我们要构建一个新闻处理系统，主要方向是实现AI提炼和代替分类。不同与其他的新闻分析软件，或者大语言模型，我们的系统可以批量处理大量新闻（千级），同时提供用户关心的相关新闻的内容桶（bucket）。除了固定的话题，我们还能提供热点话题，定向搜索话题，以及话题热度和语义演化方向。

## AI use
我们将在两个地方使用AI
- 总结文章并生成相关的theme，summary。
    - AI模型是`NVIDIA Nemotron`

- 对选择出来的桶里的文章进行可理解语言的总结转化。
    - AI模型是`NVIDIA Nemotron`

## Structure
1. 对于Input的文章进行AI summary，并生成一份去除噪声之后的关键词文本。
2. 对于1步骤的summary进行embedding，生成vector。
3. 已经生成的文章储存成数据结构形成semantic space。
4. 进行bucket取样
    1. 固定桶（fix bucket）：给定20个热点话题，制作成向量，并且寻找距离最近的top10新闻；
    2. 自由桶（query bucket）：用户输入想要查询的话题，对用户的查询进行embedding，寻找距离最近的top10新闻；
    3. 簇类桶（cluster bucket）：使用k-mean算法（或者HDBSCAN）寻找聚集的簇类新闻。
5. 进桶总结，用AI对桶里面的新闻进行总结并生成一份可供用户阅读的新闻报告。
6. 计算趋势，相关度，热度，输出给后端。


## Input
- 完整文章，进行批量处理
- 可能附带一些相关数据

## Output
- 桶总结
- 相关文章的缩略信息
- 文章编号和数据
- 趋势，相关度，热度

## Module

1. 输入预处理
2. ai文章转化模块
    - 输入：文本
    - 实现：AI
    - 输出：文章总结，文章压缩
3. embedding模块
    - 输入：文章压缩文本
    - 输出：向量
4. 向量数据结构管理
    - 输入：向量
    - 储存：向量空间。小规模用文本储存即可，解耦化，保留规模扩大化之后的数据结构接口
5. 固定桶查询
    - 调用：向量空间
    - 静态结构：话题列表。固定话题或话题压缩成的向量
    - 优化：每一个话题加入就对话题进行查询预处理，增加固定桶查询作为第一访问方式的查询速度
    - 输出：邻近10个文件列表
6. 自由桶查询
    - 输入：用户查询文本
    - 调用：向量空间
    - 复用：embedding模块
    - 输出：邻近10个文章列表
7. 簇类桶计算
    - 实现：k-mean
    - 运行：对于每一个输入空间的向量进行维护
    - 查询：对于每一个查询的向量给出所属的簇类
8. 桶总结
    - 输入：桶向量对应的文章列表
    - 实现：AI总结成自然语言
    - 输出：自然语言
9. 热度计算
    - 输入：桶数据
    - 实现：时间密度差
    - 输出：热度
10. 趋势计算
    - 输入：向量坐标
    - 实现：算出该点属于哪个簇类，并计算平均距离
    - 输出：趋势话题，相关度
11. 输出打包模块
