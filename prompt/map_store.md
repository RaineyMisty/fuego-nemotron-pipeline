# map

## 设计
- 数据1000x384的二维数组就好
- 一行代表一个文章，包含文章id,384维向量，校验码
- 末尾校验码用哈希进行去重维护
- 数学意义上的 map 永远就是：\[A\in\mathbb R^{N\times384}\]ID 和 checksum 是它旁边的索引

## 接口
- 对完整的二维向量组进行存储
- 对单个数值进行去重增量，只要确保同一文章不会重复添加就好
- 查询输出完整的二维向量地图
- 查询输出给定点邻近的top几的点
    - 数学上有\(score_i=a_i^Tq=\cos(a_i,q)\)
- 查询输出给定向量点邻近的top几的点
    - 数学上假设我们有 20 个 bucket vectors：\[B\in\mathbb R^{20\times384}\]那么直接：\[S=BA^T\]得到：\[S\in\mathbb R^{20\times N}\]
